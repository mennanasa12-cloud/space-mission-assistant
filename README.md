# Space Mission Assistant

Practice project to learn ML, Deep Learning, RAG, Agents, and Automation
before applying these skills on the graduation project.

See `architecture.md` for the full design doc.

## Setup
```
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
```

## Run
```
uvicorn api.main:app --reload
```
